# 外汇日报生成

严格按五步顺序执行,任何一步不得跳过。数字纪律条款不可协商。
设 DATE = 参数给出的日期(YYYY-MM-DD);未给参数时 DATE = 今天(UTC)。
全部命令在仓库根目录执行。

## 第 1 步:采集快照(脚本)

运行:`python3 -m scripts.collect --date DATE`

确认 `data/DATE.json` 已生成;**若不存在,立即终止并报错**——采集是前置步骤,
禁止在无快照时生成报告。命令输出的 gaps 列表记下,后面缺漏节要用。

## 第 2 步:生成要点表(LLM,产物落盘)

只读 `data/DATE.json`,写 `briefs/DATE-brief.md`,模板:

    # 要点表 DATE

    ## 跨币种共同主线
    -(≤3 条候选,基于快照事件与年历命中归纳)

    ## USD
    - 昨日事件 top:<title>(<domain>,采见 <seendate>)……至多 3 条
      (选取:FX/货币政策相关优先;与任一共同主线候选方向相反的标题至少
      保留 1 条,快照中没有反向标题则不强凑)
      **每条必须带 seendate 原文**。GDELT 查询窗跨越不止一个自然日,回来的条目
      未必属于昨日:seendate 的日期部分不是 DATE 前一日的,行尾标
      "(采见日非昨日)";seendate 缺失或无法辨认的标"(采见日不明)"。
      与 official 同理——采样口径不等于当日市场事件。
      **`channel` 为 `gnews` 时**:`url` 是 Google 跳转链、**不是原文直链**,
      引用一律以 `domain` 标出处,禁止把跳转链当原文地址写进报告;该通道的
      seendate 是**发布时间**(比采见时间更准),`channel` 为 `gdelt` 时才是采见时间。
      **`attributable_source_absent`**(脚本算好,三态,与 `articles` 一一对应):
      为 **true** 时含义是"未取得可署名来源的报道",**不是"该国昨日无新闻"**
      ——写成后者即违反禁令 5;为 **false** 时不得使用这句话,哪怕
      `gnews_filter.kept` 为 0(那说明补位拿到了条目,正列在上面);为 **null**
      时(`articles` 为 null,两条通道当日都没跑成)两句话都不准写,只按
      缺漏节如实陈述该币种事件采集失败。
      **禁止**据 `source_capped` 自行拼装任何关于条数多寡的话术:它只陈述一个
      条目级事实 —— 落盘该条目的那条通道,本次返回的原始样本顶到了它自己的
      上限;事件面的判定一律以 `events_verdict` 为准(它读的是 `sample_capped`,
      即主通道与补位通道取并,覆盖面比条目自己那个布尔更宽)。
    - 官方公告:<title>(<issuer>,发布于 <published>)……至多 3 条,取自
      events.<币种>.official(央行官方 RSS,可署名高可信;该币种无 official 键
      时写"无")。**每条必须带 published 原文**;RSS 只给"最新 N 条"、不按日期
      过滤,实测 2026-08-11 抓到的三条 Fed 公告全部发布于 7 月。发布日不是
      DATE 或 DATE 前一日的条目,行尾标"(存量背景,非昨日发布)";
      published 缺失或无法辨认的标"(发布日不明)"。
    - 数据发布:<indicator> 最新 <value> 期 <period>,前值 <prev>(截至 <prev_period>)
      (滞后 <lag_months> 个月,来源 <source>)——该条目含 `source_changed_from` 时,
      行尾必须加"(口径已由 <source_changed_from> 切换为 <source>,与前值不可比)"
      (`prev_period` 存在时必须写出:政策利率是日频序列,它的"前值"指的是**上一次
      变动之前的水平**,不带日期就是歧义的。`prev` 为 null 时写
      "前值 不可得(回溯窗口内未观测到变动)",**MUST NOT** 写成与最新值相同的数
      ——等值会被读成"持平",而事实是窗口内没看到变动。`prev_period` 不存在的
      条目照旧只写"前值 <prev>")
      (列出条件:is_new_release 为 true、**或含 `source_changed_from`**、
      或与年历命中相关;没有写"无"。
      ——`source_changed_from` 必须单独作为列出条件:换源时采集层会把
      `is_new_release` 强制置 false(期号跳变来自换源、不是新发布),只按
      is_new_release 过滤会把换源披露整个滤掉,而那正是最需要说出来的一条。
      例外:本币种"昨日事件 top"为空时,
      可列快照 macro 中该经济体的政策利率与最新 CPI(有哪项列哪项),行尾标
      "(存量背景,非昨日发布)",给该币种的触发条件留数值锚点——数字仍逐字抄快照;
      该经济体 macro 也无值时照旧写"无")
    - 汇率变动:primary <primary>(定盘日 <ref_date>),prev <prev_primary>
      (定盘日 <prev_ref_date>);两个定盘日相同时改写"参考价未更新(仍为
      <ref_date> 定盘),无价格变动可言"——**只写这个事实,不许补原因**
      (为什么没出新定盘,快照里没有任何输入能回答);USD 为基准货币,本行写"—"
    - 派生指标:日涨跌 <chg_pct_1d>%,5 运行日区间 <range_5d_low>–<range_5d_high>
      (<range_5d_days> 次定盘),双源偏差 <deviation_pct>(前值 <deviation_pct_prev>),
      实际利率 <real_rate.value>(政策利率 <policy_rate> 期 <policy_period>
      − CPI <cpi> 期 <cpi_period>),
      事件结论:**逐字整句照抄** `derived.events.<币种>.events_verdict`。
      它已经把当日条数、采集上限触顶、原始样本触顶、通道更换、结构不可识别
      的条数全部折算进一句话;照抄整句,不要摘出其中的数字另行造句。
      **禁止**据 `count_capped` / `sample_capped` / `main_sample_capped` /
      `channel_changed_from` / `dropped_malformed` 自行拼装任何话术。
      该键不存在或为 null 时,本行写"结论句不可得(快照未落结论句)",
      并且**禁止**自行补一句结论。**这个标签只陈述"快照里没有这一句",
      不判定快照新旧**——属哪一种情形(第 5 步分成两支)由第 5 步的判别标准
      决定:采集窗口仍覆盖 DATE 时,先按第 5 步重跑第 1 步采集、再回本步重做;
      窗口已移过时才就此定稿。
      前值 <count_prev> 与变化 <count_delta> 仍可引用,为 null 时写"不可得"。
      (全部逐字抄快照 derived 节;某项为 null **或该键不存在**时写"不可得",
      禁止自行补算、禁止自己去数文章篇数。**`count_prev` 与 `count_delta` 只准
      报数值**,不得据它们自行下"持平/增加/减少/回落"一类判断——事件面的
      判定一律以 `events_verdict` 为准(两天都撞上采集上限时该差值恒为 0,
      把它写成"与前值持平"就是把管道读数当成市场事实,
      该失败模式在本仓库已发生六次)。USD 为基准货币,
      derived.rates 无 USD 条目,本行不写日涨跌与区间)
    - 年历命中:<bank> <event>(<date>)(没有写"无")
    - 缺漏:<gaps 中 scope 为本币种或 all 的条目>(没有写"无")

    ## EUR
    (同 USD 结构;汇率行填 EUR 的 primary/prev_primary)

    ## PHP / ## THB / ## BRL
    (同上,各一节)

    ## 快照缺漏总表
    - [<source>/<scope>] <reason>(逐条照抄快照 gaps;为空写"无")

**数字纪律:要点表中每个数字必须从快照 JSON 逐字复制**(60.843 就写 60.843,
不得写 60.84)。**你自己禁止做任何计算**——涨跌幅、百分比、差值、区间一律不得心算;
这些派生量由采集脚本算好放在快照 `derived` 节,逐字引用即可。`derived` 中为 null
的项写"不可得",禁止自行补算。禁止写快照里不存在的任何数字。
rates 中 suspect 为 true 的币种,汇率行须注明"(双源偏差超阈,数据可疑,
主源 <primary> / 副源 <secondary>)"。

## 第 3 步:注入复盘材料、生成附录 A(脚本)

先运行:`python3 scripts/review.py --date DATE`

它把"## 复盘材料"追加到要点表末尾,并把**时限已到**的观点逐条判定,
结论与依据句写回决策日志的 `review.status` / `review.basis`。

块里有三种行,第 4 步各有各的用法:

- **带计数的声明行**(每天都有):`到期复盘 N 条;未到期 N 条顺延;已定论 N 条
  不再复盘;结构化字段之前的历史观点 N 条不在本节复盘范围`。**照抄进复盘节**,
  一个数都不许改 —— 一条都没到期时它就是本节的全部内容,不得静默留空节。
- **结论行**(`… | 复盘句: <整句> | 结论: <四档之一>`):每条到期观点一行。
  那一整句是第 4 步复盘节结论的**唯一来源**。
- **顺延登记行**(`- 顺延 | …`):时限没到的观点,**没有结论**。它在这里只为
  两件事:让你看得见还在观察哪几条,以及让「本期相对上期的变化」节引用这些
  观点登记时的数时有出处。**不得把它写成一条复盘结论。**

四档的含义(互斥且穷尽,由 `scripts/claims.py` 的判定函数给出):

| 档 | 含义 |
| --- | --- |
| 未到期 | 时限还没到,仍在观察。**不进复盘节的逐条行** |
| 命中 / 未命中 | 时限内有足够观测,可判 |
| 无法判定 | 时限已到但观测缺失,依据句里写明缺的是哪一次观测 |

**「未到期」与「无法判定」是两件事,不得混写。** 把"还没到该看的时候"写成
"看了但看不出来",正是 2026-08-14 之前 40 条里 33 条挤在「无法判定」的成因。

再运行:`python3 scripts/appendix.py --mode daily --input data/DATE.json`

它把附录 A 整块打到 stdout,**第一行就是该块自己的标题行**。第 4 步把这一块
**原样贴进报告**:一个字符都不改、不补、不删行、不改行序。管道面的事实
(当日有几条、顶没顶到上限、走的哪条通道、双源差多少、采见日属哪天、公告是不是
存量)全部由这一块承担 —— 你不转抄、不改写,也不把其中任何一句搬进正文。

## 第 4 步:生成日报(LLM)

**只依据 `briefs/DATE-brief.md`(含复盘材料)与第 3 步的附录 A 整块**,
写 `reports/daily/DATE.md`。

### 写作顺序(与模板的呈现顺序**故意不同**)

**按下面的顺序生成**,写完一档再进下一档;不得按模板从上往下写:

1. **五个币种节的证据三环**(驱动 → 传导 → 是否已反映),五节全部写完;
2. **各币种节的判断环**(关键假设 / 替代解释 / 翻转指标),由第 1 档推出;
3. **速览表** —— 每一行从该币种节第 2 档的判断**导出**,不得反过来;
4. **执行摘要** —— **最后写**,只从已经写定的币种节与速览表里取。

**禁止先写执行摘要或速览表、再回填币种节。**

理由是实测,不是风格偏好:把结论字段排在理由字段之前,模型就直接作答、
不再推理。同一模型在 GSM8K 上自由文本得分 86.51,受约束的结构化格式下
掉到 23.44,而解析错误率只有 0.148% —— 差距不是格式解析造成的;机制是
100% 的响应把 answer 键放在了 reason 键之前,零样本思维链因此退化成
零样本直答。模板的**呈现**顺序是给读者的(先看结论),**生成**顺序是给
推理的(先立证据);两者一致就等于先答后编理由。

**读者要的是清晰的逻辑链条。**这一步唯一的成品标准是:每个币种节读下来
是一条完整的链——驱动 → 传导 → 是否已反映 → 分歧与判断;摘要与速览让人
一眼抓住当日最强的那条链。凡是为了让某道闸门变绿而牺牲可读性的写法,
一律判为不合格。

**节序固定,不得换序、不得增删节。**`## 附录 A:…` 那一行起是附录区。
下面凡是说"正文"的规则(禁令 3、7、8、10)只管**附录区之前**的部分,
管道面的事实一律留在附录区;其余禁令全篇有效:

    # 外汇日报 DATE

    ## 执行摘要
    -(3–5 条列表行;每条 = 一个判断 + 时限 T+N,一条只放一个判断。
      **本节最后写**(写作顺序第 4 档),只从已写定的币种节与速览表里取。
      **首条必须是当日最强的那条链**,其余按跨币种相关性排序。
      允许:币种名、要点表里的数字、T+N、`[@键]`。
      校验器的硬上限是 6 条,但 6 条不是目标——写不满 5 条就少写)

    ## 速览

    | 币种 | 条件方向(时限) | 核心依据 | 失效条件 |
    | --- | --- | --- | --- |
    | USD | <可观测触发> → 关注<方向>(T+N) | <≤2 项,每项带 `[@键]`> | <价格或指标的可观测量> |
    (EUR / PHP / THB / BRL 各一行,五币种五行,一行都不许少)
    (**本表由各币种节的判断环导出**,是写作顺序的第 3 档,不得先填表再回写节;
     「条件方向」必须与当日写进决策日志的 trigger **同源同字**;
     「失效条件」必须是价格或指标的可观测量,不得是"若无新增信息"一类,
     并与该币种节判断环的**翻转指标同源同字**)

    ## 美元(USD)
    **驱动**:……
    **传导**:……(A → B → 汇率,并点名影响传导来源)
    **是否已反映**:……
    **分歧与判断**:关键假设……(不成立则……);替代解释……(其翻转指标:……);
    翻转指标:……(T+N)

    ## 欧元(EUR)
    (同结构;随后 ## 菲律宾比索(PHP)、## 泰铢(THB)、## 巴西雷亚尔(BRL))

    ## 昨日观点复盘
    - <复盘材料的带计数声明行照抄,一个数都不改>
    - <复盘句整句照抄> —— <一句说明:该观点的分歧点是否被市场检验>
      (**每条结论行一行**;顺延登记行不在此列,至多在末尾用一句话交代
      顺延几条、分别是哪几天的观点,不得给它们写结论词。
      复盘材料写"首次运行"时,本节正文写"首次运行,无历史观点可复盘")

    ## 本期相对上期的变化
    - USD:<一句话——本期判断相对上一份日报变了什么,四选一,见下方细则>
    (EUR / PHP / THB / BRL 各一行,五币种五行,一行都不许少;
     上一份日报不存在时,本节正文写"首次运行,无上期可比",不写五行)

    ## 附录 A:……
    (第 3 步 `appendix.py` 的 stdout **整块原样贴**,含它自己的标题行;
     这一块你一个字符都不写)

    ## 附录 B:出处
    - [@<键>] <标题> — <domain 或发布方>,发布 <时间戳原文>
      (正文与速览只出现 `[@键]`,完整出处只在这里。
       键格式 `[@<币种码><小写字母>]`(如 `[@USDa]`)或 `[@RR-<经济体>]`;
       **键内不得含数字**——`[@S15]` 会被 NUMBER_UNTRACEABLE 当场拦下)

    ## 附录 C:数据缺漏与影响
    - [<source>/<scope>] <reason> — 影响:<哪一条判断因此降档>
    (逐条对应要点表"快照缺漏总表";总表为"无"时本节正文恰为一个字:无)

### 币种节只有一种体裁:四环,每一节都要写满

**每个币种节都必须写完整四环,判断环三件(关键假设 / 替代解释 / 翻转指标)
一件不许少。没有"数据薄的那天可以少写"这一档。**

(2026-08-14 删除了此前的 minimal 档 —— 它规定"当日无可用增量"时该节只写
一行、逐字抄 `derived.body_plan.<币种>.line`。删它有两条独立理由:
① 那一行的内容「本日无可用增量,不更新判断」正属下面禁令 7 禁止写进正文的
措辞,**执行它就违规**;② 校验器那侧有一条对应豁免,声称"该节只准写一行、
本就没有判断环"就不查判断环,而实测 reports/daily/2026-08-10.md 被判 minimal
的四节各写着 270–322 中文字的完整四环 —— 依据当场为假,四节的判断环因此
白白不查。`derived.body_plan` 整块已从快照删除,要点表不再有"体裁"这一项。)

**数据薄的那一天怎么写**:该币种当日没有新事件、没有本地新发布、没有新定盘
时,判断环仍要从**存量事实**拉出来 —— 政策利率、实际利率、CPI 同比、
`range_5d_low`/`range_5d_high` 的区间上下沿、双源偏差,这些都在快照里,
都是可引的当前值。关键假设锚一个这样的当前值(校验器的 `ASSUMPTION_UNANCHORED`
查的就是它),替代解释与翻转指标照常写。**采集口径与缺漏一律只落附录 A 与
附录 C,不进正文。**"今天没有新消息"本身不是判断,也不许当成判断写出来。

四环链条,四个粗体行首**齐全且顺序固定**,一环一行:

| 环 | 这一环必须交付什么 | 建议篇幅 |
|---|---|---|
| `**驱动**` | 当日有可署名事件就写事件(带 `[@键]`);没有事件就写**当前主导变量**这个结构项(例:"本日主导变量是利差结构本身:实际利率 -1.613 为五经济体最低")。**不写否定句** | ≤80 中文字 |
| `**传导**` | "A → B → 汇率"三段必须出现;B 只能取 利差 / 风险溢价 / 资金流 / 政策空间 之一,并**显式命名影响传导来源**(见下)。**这一环要用得上第一环** | ≤80 |
| `**是否已反映**` | 至少引一个价格证据(参考价对区间边界、实际利率、双源偏差),回答"第二环那层在价里有没有" | ≤60 |
| `**分歧与判断**` | **三件齐全**:关键假设 / 替代解释 / 翻转指标(见下)。分歧点**必须是前三环推出来的** | ≤110 |

**任何一环与上一环无关,即为断链**,断链等同于本步失败。四环加起来约 300
中文字,写不满不要注水。**320 是四环预算之和,校验器硬上限 330 —— 判断环
的三件是不可压缩项**:装不下时压缩"是否已反映"与"驱动",绝不允许删掉
关键假设、替代解释或翻转指标中的任何一件来腾字数。

#### 传导环:必须命名"影响传导来源"

只说 A 与汇率相关是不够的,要说**这条影响是通过什么传到汇率的**。写法是
在"A → B → 汇率"里把 B 那一跳的**来源**点名:是谁的头寸/资金/定价行为
把 A 变成了汇率上的压力(例:"美债实际收益率走高 → 套息头寸的融资成本
上升 → 高息货币多头减仓 → 汇率")。**只写"A 与汇率同向/相关"即为不合格**
—— 相关性不是机制,读者无法据它判断这条链什么时候会断。

#### 引 ECB 政策传导做归因时,采用 ECB 自己的层级

ECB 官方的传导机制分解里,**汇率不是一级渠道** —— 它挂在"影响资产价格"
之下。因此:**凡引 ECB 权威支撑一条归因,就必须按 ECB 的层级来写**
(先到资产价格,再到汇率),不得把汇率写成 ECB 认定的一级渠道。
反过来,用我们自己那四类机制(利差 / 风险溢价 / 资金流 / 政策空间)叙述时
**不要引 ECB 权威** —— 那是拿它的名义支撑一个它不认的结构。

#### 判断环:关键假设 / 替代解释 / 翻转指标

三件都要写出来,缺一件即本步失败:

| 件 | 必须交付什么 |
|---|---|
| **关键假设** | 这条判断**依赖的假设是什么**,以及**假设不成立时判断会怎样**。两半都要写——只写假设、不写"不成立会怎样",等于没交代风险 |
| **替代解释** | **至少一条**对同一组证据的**不同解释**,并且**它自己也要带一个翻转指标**(什么一旦出现,说明该走替代解释那条路) |
| **翻转指标** | **什么一旦出现就改判**。这比"失效条件"更强:失效条件是"没发生就作废"(消极、常常等不到),翻转指标是"出现即改判"(积极、可观测、有日期或价位)。必须是价格或指标的可观测量,带 T+N |

速览表"失效条件"那一格照旧填可观测量,与本环的翻转指标**同源同字**。

#### 「本期相对上期的变化」怎么写

上一份日报 = `reports/daily/` 里日期小于 DATE 的最大者。逐币种一句话,
**四选一并且写具体**:

- **方向变了**:由关注 X 改为关注 Y,并写明**是哪一环推翻了上期**;
- **触发位变了**:方向没动,但触发条件的可观测量或阈值换了,写明换成什么、
  为什么换;
- **依据变了**:方向与触发位都没动,支撑它的那一环换了证据,写明换成哪条;
- **无实质变化**:**必须写明为什么没变** —— 上期依赖的关键假设本期仍成立、
  且上期定的翻转指标一个都没出现。

**不得留空,不得写套话。**"维持原判""继续观察""基本面未变""方向不变"
这类句子删掉之后本节信息量不变,一律判为套话。

**禁止与上一份日报的同节逐字重复。**同一句话连写两期,读者分辨不出
"判断真的没动"与"这一节根本没写"。校验器将做跨期逐字重复检测
(下一阶段实现),现在先按规矩写。

**数字上的硬约束(会当场炸校验器,务必照做):**本节的数字白名单与全篇
一样,是**当日**快照与要点表,**上一份日报不在白名单里**。所以上期的
阈值、价位、指标值若不在本期要点表里,**只描述它变了、不要把那个数写出来**
(写"触发位由上期的水平上移"合规,写出上期那个具体数字会被
`NUMBER_UNTRACEABLE` 当场拦下)。

依据:情报体系的评审标准点名周期性产品(原文举的就是每日危机报告),
要求**必须说明本期判断相对上期有何变化,且不得使用模板套话**。这一条
直接对着本仓库的实测缺陷:三个币种的实际利率四天一字未变,却被写了四遍。

**禁令(违反任何一条即校验失败):**
1. 禁止无条件方向预测——所有判断必须是"若 X 则关注 Y"的可观测触发式,
   并且带时限 `T+N` 与失效条件。**禁止同义反复**:"升破上沿则关注区间上移"
   是把定义复述一遍,不是判断;分歧点、方向、时限、失效条件四件必须都在。
2. 数字只准逐字抄自要点表(其唯一源头是快照,含脚本算好的 derived 派生量);
   你自己禁止计算、估算、回忆任何行情数字。
3. 缺漏节列出的数据,正文禁止引用或臆测。需要交代某一环没有证据时,
   只准写"本判断只建立在 <X> 上"并把原因留给附录 C,**禁止在正文描述采集过程**。
   GDELT 缺漏但 official 有条目时,该币种改用官方公告归因,并注明发布方。
4. 市场共识/预期值只在 GDELT 文章标题明说时可用,且必须标"据报道"转引;
   引自 official 的内容标"据<发布方>公告",不用"据报道"(那是转述,这是一手)。
   **只有发布日为 DATE 或其前一日的公告才能写进"驱动"环**;要点表标了
   "存量背景"或"发布日不明"的条目,只能出现在"传导"或"是否已反映"里作背景,
   并保留发布日或"发布日不明"的标注。把上个月的公告写进"驱动",就是把管道
   取样口径当成了当日市场事件(该失败模式在本仓库已发生六次)。
   引用滞后 6 个月以上的宏观值时必须带上滞后月数,不得当作当期数据陈述。
5. **禁止把管道状态变化叙述成市场事实。**具体:某指标的 `prev` 为 null,或其
   `source_changed_from` 存在(当日换了数据源),则该指标一律禁止用
   "升至/降至/回落/走高/收窄/扩大"等比较表述,也不得据此写触发条件——
   换源与期号前移造成的数值跳变不是行情。此时只陈述当期值、期号与滞后月数。
   (2026-08-11 实际发生过:美国 CPI 口径由 IMF 镜像切到 BLS,期号前移 11 个月,
   报告把 0.83 个百分点的口径差写成了"通胀升至 3.531、实际利率被压到 0.844"。)
   **同理,要点表没有给出"变了"的证据时,禁止用上述变化动词**;
   读数与前一日相同就写"较前一日未变",或者根本不写。
6. 禁止逐条罗列快照原始数据(流水账);只呈现驱动结论的关键数字。
7. **正文零管道语汇。**附录 A 的标题行之前,禁止出现下列词:
   无明确驱动、采集失败、快照、无公告、官方公告条目、采集上限、原始样本、
   通道、条目、不可得、缺漏、口径不可比、下界、seendate、URL。
   **也不许换个说法把同样的意思写进正文**——"本日未取得任何可署名的新增表述"
   "本日无可用增量"与"采集失败"是同一句话的三种写法,同样违规。
   当日没有增量时,该币种的正确动作是**从存量事实(政策利率、实际利率、
   CPI 同比、区间上下沿、双源偏差)拉出四环与判断环**,不是把"我们没采到"
   扩写成三段。**这两件事必须分清**:禁的是把"没采到"注水成散文——用三个
   粗体行首承诺分析、内容全是缺漏的复述;不禁的是拿存量事实做判断——
   那些是快照里现成的当前值,依它们立论是分析,不是注水。
   分辨判据:把该节的采集口径句全删掉之后,四环还站不站得住。站不住就是注水。
   (此处此前写的是"正确动作是走 minimal 体裁的那一行"。那一行的内容本身
   就带"本日无可用增量",与本条禁令直接冲突;minimal 体裁已删,见上文
   「币种节只有一种体裁」。)
8. **不写空转句。**一句话删掉之后报告信息量不变,就删掉它。尤其禁止连续多日
   复制同一段静态结构描述(实测:三个币种的实际利率四天一字未变,却被写了四遍)。
   静态结构项只有在**为当日的判断服务**时才允许出现,且只出现在一处环里。
   每币种节正文约 300 中文字、**校验器硬上限 330**(四环预算之和 320,
   余量留给标点与键);执行摘要 3–5 条。
9. **事件结论句不经你的手。** 要点表里 `events_verdict` 那一句,由
   `scripts/appendix.py` 写进**附录 A 整块**,你按第 3 步原样贴进报告即可:
   **不转抄、不改写、不摘出其中的数字另行造句,正文禁止出现该句**。
   校验器对报告做**精确子串包含**检查,改动一个字符(含数字、标点、全角半角)
   或整句缺失即判违规——所以那一块只能来自脚本 stdout,不能手打。
   **快照未落结论句时**,附录 A 里那一行由脚本自己写成
   "结论句不可得(快照未落结论句)",此时根本没有句子可引,**本条不适用**于该币种,
   并且**禁止自行补造**一句结论句。这一豁免的适用范围以第 5 步的判别为准:
   `VERDICT_SKIPPED_LEGACY` 一律免除;`VERDICT_SKIPPED_NO_DERIVED` **只在窗口
   已移过 DATE 那一支免除**——窗口仍覆盖 DATE 时是当日 derive 崩了,该按第 5 步
   重跑采集把结论句补出来。

10. **出处不打断叙述。**正文、执行摘要与速览表里只写 `[@键]`,完整出处一律
    进附录 B。键内不得含数字。同一条出处在全文只登记一次。

11. **零效应判断要显式写出来。**某条事件若你的判断是"它不影响汇率",
    **必须把这个判断本身写出来**(写成"该事件不构成汇率方向上的影响,
    因为它不落在利差/风险溢价/资金流/政策空间任何一条上"),不得默默略过。
    理由是实测:在需要修正符号方向的语境下,准确率从 73.9% 掉到 41.3%
    (降 32.6 个百分点),而**零效应的识别率只有 13.8%** ——"这条消息其实
    不影响汇率"是最难写对的一类判断,不显式写就等于没判。

12. **无关素材不得进正文。**与汇率没有因果链的事件,**放弃不写**,
    而不是写进来再补一句"与定价无直接因果"。理由是实测:仅仅一段无关文字
    就让准确率下降 12.3 个百分点,且**回应的形式被完整保留、实质却已失效**
    ——读起来仍然像那么回事,所以你自己发现不了。
    与禁令 11 的分工:**判断过的**零效应写进正文(禁令 11),
    **压根不成链的**素材直接不进正文(本条)。

     代价是要为五币种各定一套词表并长期守住口径,超出本轮范围。 -->

**决策日志(写完报告立即执行,经脚本代笔,禁止直接编辑 jsonl):**
把速览表五行的"条件方向"整理成 JSON 数组,经 stdin 传入
(`trigger` 与速览表那一格**同源同字**,不得两处各写一版):

    python3 scripts/log_decision.py add <<'EOF'
    [{"date": "DATE", "currency": "PHP", "scenario": "<情景一句话>",
      "trigger": "<触发条件一句话>", "watch_direction": "up|down",
      "claim": {"horizon": {"kind": "running_days", "n": 2, "quote": "T+2"},
                "legs": [{"currency": "PHP", "field": "primary",
                          "op": "gt", "threshold": "61.178"}]}},
     {"date": "DATE", "currency": "USD", "scenario": "…", "trigger": "…",
      "watch_direction": null,
      "claim": {"horizon": {"kind": "open", "quote": null},
                "legs": null,
                "unstructurable_reason": "<散文哪一句没有可机器求值的阈值>"}}]
    EOF

**`claim` 是判定入口,你在这里只做两件事:抄,和选。**

- `threshold` 是**字符串**,逐字抄自这一条自己的 `trigger`(也就是速览表那一格)。
  一位小数都不许改,不许自己算、不许四舍五入。写成 `0.8669` 去对散文里的
  `0.86693` 会被当场打红(判据是"作为一个完整的数出现",不是子串)。
- `horizon.quote` 同样逐字抄自 `trigger`(如 `T+2`、`在下一次定盘`、
  `时限:2026-09-11`)。散文里**没写**时限时,写 `{"kind": "open", "quote": null}`
  —— 不许编一个。
- `field` 从固定枚举里选:`primary`(参考价)/ `range_5d_high` / `range_5d_low` /
  `cpi_yoy` / `policy_rate`。
- `op` 从固定枚举里选:`gt` 高于 / `gte` 不低于 / `lt` 低于 / `lte` 不高于 /
  `eq` 等于。
- 触发条件是**合取**(A 且 B)时,`legs` 写多条,每条都要有自己的阈值。
  其中任何一条没有阈值(如"停在原地""继续同侧"),**整条**写 `legs: null`
  并说明 —— 只登记有阈值的那一半,会把没满足的合取判成命中。
- 散文里确实没有可机器求值的阈值时,`legs` 写 `null` 并在
  `unstructurable_reason` 里说清是哪一句。**不得编造阈值。**

`horizon.kind` 三选一:`running_days`(配 `n`,运行日 T+N)/ `date`(配 `on`,
绝对日期 `YYYY-MM-DD`)/ `open`(散文没写时限)。

watch_direction 语义:USD/该币汇率方向,"up"=该币对美元走弱;USD 自身填 null。

**触发条件硬约束(trigger 字段):必须绑定市场可观测变量**,三选一:
- 价格越过区间边界(引 derived 的 `range_5d_low`/`range_5d_high`)
- 某指标相对上期值(引快照 macro 的 value/prev,或 derived 的实际利率)
- 年历上某个具体日期的事件落地(引 `calendar_hits` 或年历中的发布日)

**禁止**把"事件源恢复""采集恢复""数据补齐"这类**系统自身状态**写进 trigger。
理由:那押注的是管道健康度而非市场,次日无论涨跌都判不出对错——2026-08 试运行
25 条观点里 20 条如此,结果 0 命中 0 未命中,复盘环等于空转。
某币种当日事件采集失败时,用要点表里的存量背景值(政策利率/CPI)作数值锚点写
市场型触发条件,不要退回自指形态。

**复盘结论:结论词由脚本给出,你没有语法可以自撰。**

复盘材料每条**结论行**里都有一段 `复盘句: <整句>`。那一句由
`scripts/claims.py` 的判定函数按该观点**自己登记的时限**算出,
是该条观点**唯一**的结论来源。

1. 报告"## 昨日观点复盘"节里,该观点那一行必须**逐字包含**这一整句
   (一个字符都不改),后面再补**一句**说明:该观点的分歧点是否被市场检验。
2. 补充说明里**禁止出现你自撰的结论词**(命中 / 未命中 / 无法判定 / 未到期)。
   这些词只能作为被引用的那一整句的组成部分出现——即结论词只有一个来源。
3. **回填是脚本自己做的,没有你的入口。** `scripts/review.py` 在第 3 步已经把
   结论与依据句写进 `review.status` / `review.basis`。此前那个让你回填 verdict
   的 `set-review` 子命令**已删除**,再调用会直接 rc=2。

**你不判断触发条件是否发生,也不据此推翻脚本结论。**这条以前是反的:
让 LLM 用"触发条件未发生"一票否决脚本结论,实测 8 条决定性结论只有 2 条被采纳,
其余被改写成"无法判定"——读者因此看不到任何有果的复盘。触发是否发生现在由
判定函数按 `claim` 机械求值,不再是复盘时的自由裁量口。
方向核对句写"参考价未更新(仍为 <ref_date> 定盘)"时,那一句已经把脚本能说的
话说完了(两天是同一个定盘日),照引即可,不得改写成"价格持平"、不得据此另下
市场结论,**也不得替它补一个原因** —— 脚本手上只有两个定盘日期,没有任何日程
输入,补出来的原因一律是编的,而这一句会被逐字引用进正文。

## 第 5 步:校验(脚本,不可跳过)

运行:
`python3 scripts/check_report.py reports/daily/DATE.md data/DATE.json --brief briefs/DATE-brief.md --prior reports/daily/前一日.md --decision-log state/decision-log.jsonl`

三个溯源入参是**必给项**,不是叮嘱:日报模式下缺任何一个,校验器**返回 2**
